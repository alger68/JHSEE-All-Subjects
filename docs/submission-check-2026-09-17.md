# 交卷前檢查流程

延續使用者「繼續」要求，完成既有交卷流程的介面改進。

先前公開網站測試在呼叫瀏覽器原生確認視窗時逾時。這是測試環境的觀察，不能據此認定所有手機都有相同故障。本次將交卷確認改為站內 `#/exam-check` 頁面，讓流程可見、可返回，也能列出需要再檢查的題目。

## 行為

- 頂端、答案卡及末題「交卷」按鈕都先開啟檢查頁，不立即結算。
- 顯示已答、未答與標記不確定的題數；點題號可直接返回該題。
- 「返回繼續作答」保留題號、答案、開始時間及非選／寫作草稿。
- 「確認交卷」才保存結果，按鈕綁定目前測驗識別碼；已交卷不再次結算。
- 檢查頁重新整理仍可續答；檢查期間照常計時，到時自動交卷。
- 官方模式不在確認前顯示正確答案。草稿摘要只顯示是否填寫與字元數。
- 過期的確認頁網址在沒有進行中測驗時顯示會考中心，不自行開新卷。
- 使用原生 HTML 按鈕、可換行題號清單與行動裝置安全邊界；確認頁標題取得鍵盤焦點。

## 驗證

- 新流程 3 項測試先失敗，再修正至通過。
- 既有 14 項整合測試改為兩階段交卷；新增 5 項測試，整合測試共 19 項通過。
- 完整測試共 80 項通過；正式建置與題庫資產驗證通過。
- 本輪雲端瀏覽器連線仍逾時，未完成手機實機與新流程的公開網站視覺操作驗證。沒有把自動化 DOM 測試當成手機實機驗證。

原有官方題本、題庫、計分規則與報告保存方式沿用前版。
