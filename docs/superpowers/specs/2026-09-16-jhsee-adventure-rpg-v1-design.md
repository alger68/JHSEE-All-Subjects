# JHSEE Adventure｜116 會考大冒險 RPG V1 設計規格

日期：2026-09-16  
專案：JHSEE-All-Subjects  
部署：GitHub Pages  
目標使用者：準備 116 年國中教育會考的國三學生

## 1. 產品定位

V1 將既有「全科會考模擬學習平台」與最新確認的 RPG 學習方向整合成同一套產品。平日使用 Adventure 模式建立練習習慣；需要正式測驗時，沿用 CBT Exam 模式。原有 `JHSEE-English-Adventure` 維持獨立，不修改、不覆蓋。

核心循環：

> 選科世界 → 挑戰 5 題關卡 → 即時回饋 → EXP／金幣／Combo → 錯題復仇 → Boss → 能力分析 → 推薦下一關

## 2. V1 可交付範圍

V1 必須包含：

- 手機優先的遊戲 Lobby 與五科入口：國文、英文、數學、自然、社會。
- 每科至少一條可玩的示範關卡，共至少 30 題原創模擬題。
- 普通關卡：5 題、5 顆生命、答對造成傷害、答錯扣生命。
- Combo、EXP、等級、金幣、星級與關卡解鎖。
- 每科 Boss：綜合題挑戰與結算。
- 每日任務、每日寶箱、至少完成 10 題才計入 Streak。
- 錯題復仇與 0–3 熟練度；答對上升、答錯下降，保留下次複習日期。
- 能力分析：依科目與 topic 顯示正確率，樣本不足必須明示。
- LocalStorage 自動存檔與「重設進度」。
- 保留模擬會考入口；V1 提供跨科快速模考，考試中不顯示答案。

V1 不包含：帳號、雲端同步、排行榜、付費商城、AI API、官方題目全文匯入、AI 正式作文評分。

## 3. 畫面與導覽

首頁第一個畫面直接是遊戲 Lobby，不放行銷式大型 Hero。首屏顯示玩家等級、EXP、金幣、連續學習、會考倒數、五科世界、今日任務與主要行動。

主要 hash routes：

- `#/`：Lobby
- `#/world/:subject`：科目地圖
- `#/battle/:subject/:levelId`：普通關卡
- `#/boss/:subject`：Boss
- `#/revenge`：錯題復仇
- `#/analysis`：能力分析
- `#/exam`：快速模考

底部固定導覽：首頁、關卡、挑戰、分析、我的。

## 4. 視覺方向

採「夜色冒險地圖＋明亮能量卡」風格：深藍紫背景、青綠與金色強調色、科目專屬色、清楚的卡片層級與節制的粒子／受擊動畫。不能沿用補習班題庫列表，也不使用幼兒化卡通。

- 主要文字至少 16px，常用標籤至少 14px。
- 觸控目標至少 44px。
- 320px 寬不可水平捲動。
- 支援 `prefers-reduced-motion`。
- 正誤不只靠紅綠色，需同時有圖示與文字。

## 5. 遊戲規則

### 普通關卡

- 每關 5 題，玩家 HP 5，怪物 HP 100。
- 答對：基礎傷害 20；Combo 3 起增加至 25，Combo 5 為 40。
- 答錯：玩家 HP -1、Combo 歸零、題目加入錯題復仇。
- 答對 +20 EXP／+5 金幣；答錯仍 +5 EXP。
- 星級：90% 以上 3 星、75–89% 2 星、60–74% 1 星、低於 60% 未過關。

### Boss

- 每科 10 題，Boss HP 500，玩家 HP 5。
- 80% 以上擊敗 Boss，額外 +100 EXP／+80 金幣。
- Boss 題目依科目多個 topic 混合抽取。

### 等級

累積門檻使用 `100 × level^1.5`，畫面顯示目前等級進度；升級不扣除累積 EXP。

## 6. 題目格式

```json
{
  "id": "MATH-ALG-001",
  "subject": "math",
  "chapter": "代數城",
  "topic": "一元一次方程式",
  "grade": 7,
  "difficulty": 1,
  "question": "2x + 7 = 19，x = ?",
  "choices": ["4", "5", "6", "7"],
  "answer": 2,
  "explanation": "先移項得到 2x = 12，所以 x = 6。",
  "hint1": "先把 7 移到等號右邊。",
  "hint2": "2x = 12。",
  "source": "original",
  "tags": ["代數", "方程式"]
}
```

所有 V1 題目必須是原創模擬題，顯示「平台自製模擬題」。官方歷屆題只能保留獨立入口與來源欄位，不得冒充或混入模擬題。

## 7. 存檔結構

單一 namespace：`jhsee.adventure.v1`。內容包含 player、subjectProgress、levelProgress、dailyQuest、wrongQuestions、skillStats、attempts、settings 與 activeRun。每答一題即保存 activeRun；完成或放棄後清除。

## 8. 驗收條件

1. GitHub Pages 在手機與桌面可開啟，無資源 404。
2. 首頁五科均能進入地圖，至少一關可完整作答與結算。
3. EXP、等級、金幣、Combo、星級及解鎖規則運作正確。
4. 答錯會進入錯題復仇，熟練度可升降並持久保存。
5. 每日任務、10 題 Streak 門檻與寶箱只可領一次。
6. Boss 與快速模考均可完成；模考交卷前不洩露答案。
7. 分析頁能顯示科目／topic 統計，資料不足不過度推論。
8. 自動測試通過，沒有阻斷作答的 console error。
