# 官方會考與有效複習設計

依 2026-09-17 對話確認：官方真題、原創補強、間隔複習分開；使用者以「繼續」授權實作。

## 本次交付
- 新增會考中心，115 年官方原站題本、選擇題答案卡、英聽下載、數學非選與寫作樣卷入口。
- 官方六份選擇題卷：國文 42／70 分、英文閱讀 43／60 分、英聽 21／25 分（三選一）、數學 25／80 分（另有 2 題非選）、社會 54／70 分、自然 50／70 分。寫作獨立 50 分鐘草稿，不自動評級。
- 題本用官方 Google Drive 連結開啟；網站提示先下載或列印再開始。桌面可另開題本，手機不依賴 iframe。英聽下載 ZIP 在官方連結，先準備音檔再計時。
- 時間以開始時間計算，重整／離開頁面繼續計時；到時交卷。每次作答保存，返回可續答。
- 作答中不顯示答案、解析或答案連結。交卷後才核對選擇題。非選、作文只保存草稿並連到官方評分樣卷。
- 先修復倒數每秒全頁 render + scrollTo(0) 的根因。只更新 timer DOM。第末題提供交卷，頂端也有交卷，未答提示。
- 原創練習可選科目與年級範圍、標記猜答、看提示；全卷與短練習名稱分開。新增經核對的閱讀、生活應用、圖表資料與推論原創題。
- 所有既有題無自動 examAligned=true。只有明確考點、題型、能力、依據、審核資訊齊全時才標原創會考導向。
- 錯題保存錯因（自行選擇）、猜答、下次複習日。一天內重做不反覆增加熟練度，已熟悉題到期仍可複習。官方題以題號和原題本連結複習。
- 成績保存首次／重做／提示次數，原創與官方分開。只呈現題數正確率，不推估 A++。
- 不更動舊 JHSEE-English-Adventure 專案。保留現有 LocalStorage version 1 資料。
