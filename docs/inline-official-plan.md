# 官方題本站內閱讀

以官方 115 年原 PDF 轉為頁面影像，保持原圖、公式、選項與文章，不用 OCR 重寫官方題目。逐題模式依題號切出題目區域，題組在同一畫面附上完整共用材料；整份模式可站內翻頁。兩種模式共用原計時、答案、草稿和交卷流程。數學非選、公式頁、寫作及官方聽力音訊同樣可在站內閱讀／播放。

原 PDF 及聽力 ZIP 由官方 115 年試題頁連結取得。產生工具保存來源 SHA-256 與區域對照；所有 235 題均檢查題號、選項完整性、區域界線及題組關係。影像只在需要的頁面載入。使用者仍可選擇開啟官方原檔。

驗證：題數與來源圖檔、跨頁閱讀題組、模式切換與答案／倒數保存、最後一題交卷、錯題複習、數學及作文草稿、音訊在作答後不被重置，以及建置後靜態資源存在。
