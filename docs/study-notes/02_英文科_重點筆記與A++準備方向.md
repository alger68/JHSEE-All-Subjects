## 一、A++ 決勝五大文法核心整理

### 1. 時態一致性與現在完成式（必考 2～3 題）
- **時間/條件副詞子句「以現在代未來」**：
  - 當看到連接詞 `when`（當……時）、`before`、`after`、`until`、`as soon as`、`if`（如果）、`unless`（除非）引導「未來還沒發生的條件或時間」時：
  - **公式**：`主要子句（未來式 will + V） + when/if 子句（現在簡單式 V/V-s）`
  - > **陷阱**：若 `when` 或 `if` 意思是「何時」或「是否」（名詞子句，當 `know / ask / wonder / not sure` 的受詞），則**該用未來式就要用未來式**！
    - 例：`I don't know if it will rain tomorrow. If it rains, I will stay home.`
- **現在完成式 (`have/has + p.p.`)**：
  - 搭配 `since + 過去時間點 / 過去式子句`、`for + 一段時間`、`already`、`yet`、`ever`、`never`、`so far`、`recently`。
  - **`have been to` vs. `have gone to` vs. `have been in`**：
    - `have been to + 地點`：曾經去過（人已經回來了）。
    - `have gone to + 地點`：已經去了（人還在當地或在路上，主詞不可能是 I / you）。
    - `have been in + 地點 + for...`：待在某地已經多久了。
- **過去進行式 vs. 過去簡單式**：
  - 短動作（`when + 過去簡單式`）發生時，長動作正在進行（`過去進行式 was/were + V-ing`）。
- **過去完成式 (`had + p.p.`)**：
  - 「過去的過去」：兩個過去動作，先發生的用 `had + p.p.`，後發生的用過去簡單式（例：`The train had left before I arrived at the station.`）。

### 2. 關係子句（形容詞子句）與分詞片語（必考）
- **關係代名詞選擇表**：
  | 先行詞（前方的名詞） | 主格（後接動詞 V） | 受格（後接 S + V，可省略） | 所有格（後接名詞 N） |
  | :--- | :--- | :--- | :--- |
  | **人** | `who` / `that` | `who(m)` / `that` / (可省) | `whose` |
  | **事物 / 動物** | `which` / `that` | `which` / `that` / (可省) | `whose` |
  | **人 ＋ 動物/事物** | `that` | `that` / (可省) | — |

- **必用 `that` 的情況**：
  1. 先行詞有最高級（`the best`）、序數（`the first`）、`the only`、`the very`、`all`、`no`、`any`、`every`。
  2. 先行詞同時包含「人與物」（例：`Look at the boy and his dog that are running over there.`）。
  3. 疑問詞 `Who / Which` 開頭的問句，避免重複。
- **不可用 `that` 的情況**：
  1. **介系詞後面**（例：`the house in which I live`，不可寫 `in that`）。
  2. **逗號後面**（非限定用法，補充說明唯一特定人地物，例：`My father, who is a doctor, likes swimming.`）。
- **複合關係代名詞 `what` (`= the thing(s) which`)**：
  - `what` **前面絕對沒有先行詞（名詞）**！直接當名詞子句（例：`What you said is true.`）。
- **介系詞片語與現在/過去分詞後位修飾（減化子句）**：
  - 主動 / 進行中 ➔ `V-ing`（例：`The girl talking (= who is talking) to Mr. Lin is my sister.`）
  - 被動 / 已完成 ➔ `p.p.`（例：`The cake made (= which was made) by Mom is delicious.`）
  - 穿著衣物/配件 ➔ `in`；有著某五官/帶著某物 ➔ `with`（例：`The boy in a blue jacket with big eyes`）。

### 3. 名詞子句與間接問句（語序陷阱）
- **間接問句口訣：「疑問詞（wh-）留著，後面恢復直述句（主詞 S ＋ 動詞 V），助動詞 do/does/did 拿掉並還原時態！」**
  - ❌ `Can you tell me where does he live?`
  - ⭕ `Can you tell me where he lives?`
  - ❌ `Do you know what is his name?`
  - ⭕ `Do you know what his name is?`
  - **例外**：當 `who` 或 `what` 本身就是該子句的「主詞」時，語序本來就不變（例：`Do you know who broke the window?`）。

### 4. 被動語態、使役動詞與感官動詞
| 語法結構 | 公式與重點 |
| :--- | :--- |
| **被動語態** | `be 動詞 (依時態變化) + p.p. (+ by 人)`<br>※ 進行被動：`is/are/was/were + being + p.p.`<br>※ 完成被動：`have/has/had + been + p.p.`<br>※ 助動詞被動：`will/can/should/must + be + p.p.`<br>※ **絕對沒有被動語態的不及物動詞**：`happen`、`take place`（發生）、`appear`（出現）、`belong to`（屬於）、`cost`、`last`（持續）、`remain`。 |
| **使役動詞** (`make` / `have` / `let`) | <li>受詞「主動」做動作：`make / have / let + 受詞 + 原形動詞 (V)`</li><li>受詞「被動」被處理：`make / have + 受詞 + p.p.`（例：`I had my hair cut.`）</li><li>對照：`ask / tell / want / need / get + 受詞 + to V`（要加 `to`！）</li> |
| **感官動詞** (`see` / `watch` / `hear` / `feel` / `notice`) | `感官動詞 + 受詞 + 原形 V（強調事實全貌） / V-ing（強調正在進行） / p.p.（被動）` |

### 5. 附加問句、倒裝附和句與不定代名詞
- **附加問句（前肯後否、前否後肯）**：
  - 注意否定副詞：`never`、`seldom`、`hardly`、`rarely`、`little`、`few`、`nothing`、`nobody` 視為**否定句**，後面附加問句要用**肯定**！
    - 例：`He seldom goes to the movies, does he?`
  - `There is/are...` ➔ `..., isn't/aren't there?`
  - `This/That is...` ➔ `..., isn't it?`；`These/Those are...` ➔ `..., aren't they?`
  - 祈使句 `Open the door, will you?`；`Let's go, shall we?`；`Let us go, will you?`
  - `I am late, aren't I?`
- **數量不定代名詞 (`one` / `another` / `the other` / `others` / `the others`)**：
  - **兩者**：`One..., and the other...`
  - **三者**：`One..., another..., and the other...`
  - **不限定總數**：`Some..., and others...`
  - **限定範圍內剩下的全部**：`Some..., and the others...`

## 二、花費動詞（Spend / Take / Cost / Pay）比較表

| 動詞 (三態) | 主詞 | 句型公式 |
| :--- | :--- | :--- |
| **spend** (`spent-spent`) | **人** | `人 + spend + 時間/金錢 + V-ing / on N` |
| **take** (`took-taken`) | **事 / It** | `It + takes + (人) + 時間 + to V` |
| **cost** (`cost-cost`) | **物 / It** | `物/It + costs + (人) + 金錢 (+ to V)` |
| **pay** (`paid-paid`) | **人** | `人 + pay (+ 金錢) + for + 物` |

## 三、長篇閱讀與克漏字（轉折詞與推論技巧）

### 1. 克漏字必背邏輯連接詞與介系詞
- **表因果**：`because / since / as / for` + 子句；`because of / thanks to / due to` + 名詞/V-ing；`therefore / thus / as a result`（因此，後接結果）。
- **表轉折讓步**：`although / though / even though` + 子句（**絕對不可與 `but` 連用**，但可與 `still / yet` 連用）；`despite / in spite of` + 名詞；`however`（然而，前後常有逗號）。
- **表條件與目的**：`in order to V = so as to V`（為了……）；`so that + 子句`（以便……）；`otherwise`（否則）；`instead of + N/V-ing`（取代……而不是……）。

### 2. 閱讀題組四大題型破解法
1. **主旨題 (`What is the main idea / best title...?`)**：
   - 看**第一段最後一句**與**最後一段**，並找全文各段重複出現的「核心關鍵字」。太狹隘（只講某一段細節）或太廣泛的選項直接刪去。
2. **指代題 (`What does "it / they / this" refer to?`)**：
   - 往前找 1～2 句，單數找單數名詞，複數找複數名詞，帶入原句檢驗語意是否通順。
3. **字義猜測題 (`What does "X" mean in the reading?`)**：
   - 切勿直接選該字你背過的第一個意思！會考常考**熟詞僻義**（例如 `book` 當動詞預約、`plant` 當工廠、`run` 當經營、`fine` 當罰款、`address` 當處理/演講、`board` 當登機/董事會）。一定要看前後句的因果或反義線索。
4. **圖表/時刻表/網路留言串題**：
   - 先看題目問誰、問哪個條件（如時間、預算、年齡限制），再到圖表中用「刪去法」逐一排除不符條件的選項。

1. **發音開始前先掃描選項**：利用唸題號與導引的空檔，快速看下一題的圖片差異（動作、地點、服飾、數量）或四個文字選項的動詞/疑問詞。
