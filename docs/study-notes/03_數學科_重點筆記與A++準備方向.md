## 一、數與代數核心公式與必考觀念

### 1. 指數律、科學記號與根式運算
- **指數律**（$a, b \neq 0$）：
  - $a^m \times a^n = a^{m+n}$ ； $a^m \div a^n = a^{m-n}$
  - $(a^m)^n = a^{m \times n}$ ； $(a \times b)^n = a^n \times b^n$
  - $a^0 = 1$ ； $a^{-n} = \frac{1}{a^n}$
- **科學記號**：$a \times 10^n$，其中 **$1 \le a < 10$**，$n$ 為整數。
  - 若 $n$ 為正整數，$a \times 10^n$ 的整數部分是 **$(n+1)$ 位數**。
  - 若 $n = -k$（負整數），$a \times 10^{-k}$ 在小數點後第 **$k$ 位**開始出現不為 0 的數字。
- **平方根陷阱**：
  - $\sqrt{a^2} = |a|$（永遠大於或等於 0！例如 $\sqrt{(-5)^2} = 5$）。
  - 「$9$ 的平方根」是 $\pm 3$；但「$\sqrt{9}$」只是 $3$。

### 2. 乘法公式、多項式與一元二次方程式
- **必背乘法公式**：
  - $(a+b)^2 = a^2 + 2ab + b^2$
  - $(a-b)^2 = a^2 - 2ab + b^2$
  - $(a+b)(a-b) = a^2 - b^2$
  - 知和求積 / 知積求和變形：$(a+b)^2 - (a-b)^2 = 4ab$ ； $a^2 + b^2 = (a+b)^2 - 2ab = (a-b)^2 + 2ab$
- **一元二次方程式 $ax^2 + bx + c = 0$ ($a \neq 0$)**：
  - 解法優先順序：**十字交乘因式分解 ➔ 配方法 ➔ 公式解**
  - **公式解**：$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$
  - **判別式 $D = b^2 - 4ac$**：
    - $D > 0$：相異兩實根（二次函數與 $x$ 軸交於 2 點）
    - $D = 0$：重根 / 完全平方式（二次函數與 $x$ 軸相切於 1 點）
    - $D < 0$：無實數解（二次函數與 $x$ 軸無交點）

### 3. 等差數列與等差級數
- **第 $n$ 項公式**：$a_n = a_1 + (n-1)d = a_m + (n-m)d$
- **等差中項**：若 $a, b, c$ 成等差，則 $b = \frac{a+c}{2}$。
- **前 $n$ 項和（等差級數）**：
  - $S_n = \frac{n(a_1 + a_n)}{2} = \frac{n[2a_1 + (n-1)d]}{2} = \text{中間項} \times \text{項數 } n$（當 $n$ 為奇數時極好用！）

### 4. 二次函數頂點與圖形平移（A++ 必考）
- **標準式（頂點式）**：$y = a(x - h)^2 + k$
  - **頂點座標**：$(h, k)$
  - **對稱軸方程式**：$x = h$
  - **開口方向與極值**：
    - $a > 0$：開口向**上**，當 $x = h$ 時有**最小值** $y = k$。
    - $a < 0$：開口向**下**，當 $x = h$ 時有**最大值** $y = k$。
  - **開口大小**：$|a|$ 越大，開口越**小（窄）**；$|a|$ 越小，開口越**大（寬）**。
- **平移口訣**：「左加右減（針對 $x-h$），上加下減（針對 $+k$）」，平移不改變 $a$（開口大小與方向不變）。
- **區間極值陷阱**：若題目限制範圍（例如 $1 \le x \le 5$），務必先檢查**頂點 $x = h$ 是否在範圍內**！不在範圍內時，離對稱軸越遠端點函數值變化越大。

## 二、幾何大魔王：三角形、相似形、圓與三心

### 1. 多邊形內外角與三角形邊角關係
- **$n$ 邊形內角和**：$(n-2) \times 180^\circ$ ； **外角和**：永遠是 $360^\circ$。
- **三角形外角定理**：任一外角 ＝ 相鄰兩內角之和。
- **三角形第三邊範圍**：$|\text{兩邊差}| < \text{第三邊} < \text{兩邊和}$。
- **邊角不等關係**：在**同一個三角形**中，大邊對大角，小邊對小角。
- **特殊直角三角形邊長比**：
  - $30^\circ - 60^\circ - 90^\circ$：**$1 : \sqrt{3} : 2$**
  - $45^\circ - 45^\circ - 90^\circ$：**$1 : 1 : \sqrt{2}$**
  - 常見畢氏數：$(3, 4, 5)$、$(5, 12, 13)$、$(7, 24, 25)$、$(8, 15, 17)$、$(9, 40, 41)$、$(20, 21, 29)$。
  - 正三角形邊長為 $a$：高 $= \frac{\sqrt{3}}{2}a$，面積 $= \frac{\sqrt{3}}{4}a^2$。
  - 直角三角形斜邊上的高：$h = \frac{\text{兩股乘積}}{\text{斜邊}}$。

### 2. 平行線截比例線段與相似三角形
- **相似性質**：`AA（最常考！）`、`SAS`、`SSS`。
- **面積比與邊長比關係**：
  - **相似三角形**：面積比 ＝ **對應邊長平方比**（$a^2 : b^2$）。
  - **同高（共頂點）三角形**：面積比 ＝ **底邊長之比**（$a : b$）。
  - > **A++ 解題神技**：會考幾何壓軸題常把「相似三角形（平方比）」與「共高三角形（底邊比）」結合在梯形或平行四邊形內，先用相似找邊長比，再轉成共高求面積！

### 3. 圓形核心性質（切線、圓心角、圓周角）
- **弦心距性質**：圓心到弦的垂直線必**平分該弦**（搭配半徑 $r$、半弦長、弦心距形成**畢氏定理**）。
- **切線性質**：
  1. 圓心到切點的連線必**垂直**切線。
  2. 圓外一點到圓的兩條切線段**等長**，且圓心與該點連線平分夾角。
- **角度公式（以所對的弧度為基準）**：
  - **圓心角** $= \text{所對弧度}$
  - **圓周角** $= \frac{1}{2} \times \text{所對弧度}$（**半圓/直徑所對的圓周角必為 $90^\circ$**！）
  - **圓內角** $= \frac{1}{2} \times (\text{兩對頂弧度數和})$
  - **圓外角** $= \frac{1}{2} \times (\text{大弧} - \text{小弧})$
  - **圓內接四邊形**：**對角互補（相加 $180^\circ$）**，外角等於內對角。

### 4. 三角形「三心」（外心、內心、重心）終極對照表（必考！）

| 比較項目 | **外心 ($O$)**（外接圓圓心） | **內心 ($I$)**（內切圓圓心） | **重心 ($G$)**（重量中心） |
| :--- | :--- | :--- | :--- |
| **作圖定義** | 三邊**中垂線**交點 | 三內角**角平分線**交點 | 三條**中線**交點 |
| **核心等距性質** | 到**三頂點**等距離（$= R$ 外接圓半徑） | 到**三邊**等距離（$= r$ 內切圓半徑） | 頂點到重心 $:$ 重心到對邊中點 $= \mathbf{2 : 1}$ |
| **位置分布** | 銳角 $\triangle$：內部<br>**直角 $\triangle$：斜邊中點**（$R = \frac{1}{2}\text{斜邊}$）<br>鈍角 $\triangle$：外部 | 永遠在三角形**內部** | 永遠在三角形**內部** |
| **必背角度/面積公式** | <li>銳角 $\triangle$：$\angle BOC = 2\angle A$</li><li>鈍角 $\triangle$：$\angle BOC = 360^\circ - 2\angle A$</li> | <li>$\angle BIC = 90^\circ + \frac{1}{2}\angle A$</li><li>$\triangle ABC \text{面積} = \frac{1}{2} \times \text{周長} \times r$</li><li>直角 $\triangle$ 內切圓半徑：$r = \frac{\text{兩股和} - \text{斜邊}}{2}$</li> | <li>三條中線將 $\triangle$ 分成 **6 個面積相等**的小三角形（各占 $\frac{1}{6}$）</li><li>重心與三頂點連線分成 **3 個面積相等**的三角形（各占 $\frac{1}{3}$）</li> |

> **正三角形三心合一**：外心＝內心＝重心，且 $R : r = 2 : 1$，外接圓面積 $:$ 內切圓面積 $= 4 : 1$。

## 三、統計與機率常考陷阱

1. **四分位數（$Q_1, Q_2, Q_3$）與盒狀圖**：
   - 先將資料**由小到大排序**！計算位置 $i = N \times \frac{k}{4}$：
     - 若 $i$ 為整數，取第 $i$ 筆與第 $(i+1)$ 筆的平均。
     - 若 $i$ 有小數，無條件進位取第 $(\lfloor i \rfloor + 1)$ 筆。
   - **四分位距 $\text{IQR} = Q_3 - Q_1$**（包含中間約 $50\%$ 的資料）。
   - **盒狀圖大陷阱**：盒狀圖某一段比較「長」，代表該區間資料**比較分散（全距大）**，**不代表人數比較多**！四個區間（最小～$Q_1$、$Q_1$～$Q_2$、$Q_2$～$Q_3$、$Q_3$～最大）的人數佔比永遠各約 **$25\%$**！
2. **古典機率**：
   - 同時投兩顆骰子（或一顆投兩次），樣本空間總數是 $6 \times 6 = 36$ 種（注意 $(2,3)$ 與 $(3,2)$ 視為不同情形！）。
   - 「取後放回」vs.「取後不放回」務必看清楚。

## 四、非選擇題（6 分滿分）書寫規範

會考非選共 2 題（通常第 1 題為生活情境代數/統計應用題，第 2 題為幾何推論證明或進階規律題），每題 3 分：
1. **第一小題（通常 1 分）**：直接算對就有分，但仍要寫出算式過程。
2. **第二小題（通常 2 分，常問「誰說得對？請完整說明理由」或「幾何證明」）**：
   - **切忌只寫「甲對」或「不合理」**（只寫結論不寫過程 ＝ 0 分！）。
   - **標準三段式寫法**：
     1. **設未知數或標示條件**：「設……為 $x$」或「連接 $\overline{AC}$，在 $\triangle ABC$ 中……」。
     2. **列式與推導**：「因為（已知條件/定理），所以（推導算式）……解得 $x = \dots$」。
     3. **明確回答問題並加上單位**：「因為 $x = \dots > \dots$，故○○方案較划算／甲的說法正確。答：……」。
