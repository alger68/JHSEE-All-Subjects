## 一、字音、字形、字義與成語辨析（必拿基本分）

### 1. 常考易錯字音字形整理
| 類別 | 常見陷阱與正確寫法 / 讀音 |
| :--- | :--- |
| **形近字辨析** | <li>「按」部就班（手部，照著） vs. 「黯」然銷魂（黑部，心神沮喪）</li><li>再接再「厲」（磨刀石，引申奮勉） vs. 變本加「厲」（猛烈） vs. 雷「厲」風行</li><li>不「脛」而走（小腿） vs. 大相「逕」庭（小路，差距極大） vs. 曲「徑」通幽</li><li>名「列」前茅 vs. 興高「采」烈 vs. 直接「了」當（❌截） vs. 迫不「及」待（❌急）</li><li>鬼鬼「祟祟」（ㄙㄨㄟˋ，❌ㄔㄨㄥˊ） vs. 破「綻」（ㄓㄢˋ） vs. 粗「獷」（ㄍㄨㄤˇ） vs. 針「砭」（ㄅㄧㄢ）</li> |

### 2. 易誤用成語（褒貶與對象陷阱）
- **炙手可熱**：形容權貴氣勢盛、權力大（含貶義），**不可**用來形容商品暢銷或美食熱門。
- **首當其衝**：比喻最先受到攻擊或遭遇災難，**不可**當作「首先、第一要務」。
- **差強人意**：意思是大體上尚能令人滿意，**不是**令人不滿意。
- **曾幾何時**：才過沒多久（感嘆時間流逝快，多接變化），**不是**「曾經何時」。
- **明日黃花**：比喻過時的事物（只有「明日黃花」，**沒有**「昨日黃花」）。
- **美輪美奐**：僅用於形容「建築物」高大華美，不可形容風景或女子美貌。
- **破鏡重圓**：專指夫妻失散或決裂後重新團聚，不可用於朋友和好。
- **汗牛充棟**：形容藏書極多，不可形容人潮或貨物多。

## 二、語法核心：六書、詞性、四大句型與修辭

### 1. 漢字構造（六書）與字體演變
- **六書判別口訣**（前四為「造字法則：象指會形」，後二為「用字法則：轉假」）：
  1. **象形**（獨體、具體物象）：日、月、山、水、木、牛、羊、鳥、女、子、目、瓜。
  2. **指事**（獨體、抽象符號或象形加符號）：上、下、本、末、朱、刃、寸、甘、亦、一二三。
  3. **會意**（合體、無聲符、意義合成）：休（人依木）、信（人言）、武（止戈）、明、森、炎、淼、男、婦、尖、歪、祭、采。
  4. **形聲**（合體、形符表義＋聲符表音，占漢字 80% 以上）：江、河、聞、問、悶、圃、衷、旗、驚。
- **字體演變順序**：
  `甲骨文（商，刀刻龜甲獸骨） ➔ 金文/鐘鼎文（周，鑄刻青銅器） ➔ 小篆（秦，李斯統一文字） ➔ 隸書（漢，蠶頭燕尾，古今文字分水嶺） ➔ 楷書（漢末魏晉至今，形體方正） / 草書 / 行書`

### 2. 四大句型快速判別法
```
句子裡有沒有「是、為、乃、即、非」表等同或分類？
 ├── 有，且主語＋繫詞＋斷語（名詞性） ➔ 【判斷句】（例：天下無難事、孔子乃聖人）
 └── 沒有 ➔ 句中是否有「有、無、多、少、充滿」表存在？
       ├── 有 ➔ 【表態句】或【有無句】
       │    └── 主語＋「有/無」＋賓語 ➔ 【有無句】（例：宅邊有五柳樹、天下無不是的父母）
       └── 沒有 ➔ 看謂語是「動詞」還是「形容詞」？
             ├── 有動作行為（動詞） ➔ 【敘事句】（例：慈母手中線、我們去看海）
             └── 描寫性質狀態（形容詞/形容詞片語，無動作） ➔ 【表態句】（例：山明水秀、荷花亭亭玉立）
```
> **A++ 陷阱提醒**：並非看到「是」就是判斷句！例如「是日更定矣」（此，代詞，表態句）、「唯利是圖」（助詞，賓語提前，敘事句）。

### 3. 轉品與使動/意動用法（文言文必考）
- **名詞轉動詞**：驴不勝怒，「蹄」之（用蹄踢）；不「蔓」不「枝」（長出藤蔓、長出旁枝）。
- **形容詞轉動詞**：春風又「綠」江南岸（吹綠）；親「賢」臣，「遠」小人（疏遠）。
- **使動用法**（使……怎樣）：「勞」其筋骨（使筋骨勞累）、無案牘之「勞」形（使身體勞累）。
- **意動用法**（以……為……／認為……怎樣）：漁人甚「異」之（認為這景象很奇異）、不「恥」下問（以向下請教為恥）。

## 三、文言文 A++ 破題核心：高頻虛詞與斷句策略

### 1. 八大高頻文言虛詞一字多義總表
| 虛詞 | 常見字義與經典例句 |
| :--- | :--- |
| **之** | 1. **代詞**（他/它/這）：學而時習「之」、擇其善者而從「之」、物外「之」趣（助詞：的）<br>2. **動詞（往、到）**：送孟浩然「之」廣陵、吾欲「之」南海<br>3. **助詞（賓語提前標誌，無義）**：何陋「之」有、蓮「之」愛、唯利是圖<br>4. **助詞（放主謂之間取消獨立性，無義）**：予獨愛蓮「之」出淤泥而不染 |
| **其** | 1. **代詞（他的/它的/其中的）**：擇「其」善者而從之<br>2. **語氣副詞（豈、難道，表反詰）**：「其」恕乎！「其」真無馬邪？<br>3. **語氣副詞（大概、恐怕，表推測）**：「其」真不知馬也！ |
| **以** | 1. **介詞（用、拿、憑藉）**：何「以」為計、「以」叢草為林、徐噴「以」煙<br>2. **介詞（因為）**：不「以」物喜，不「以」己悲<br>3. **連詞（用來、以便，表目的）**：留蚊於素帳中，「以」為樂也 |
| **為** | 1. **動詞（做、當作、變成）**：項「為」之強（因為，ㄨㄟˋ）、以叢草「為」林（當作，ㄨㄟˊ）<br>2. **介詞（被）**：舌一吐而二蟲盡「為」所吞（被，ㄨㄟˊ）<br>3. **介詞（替、向、因為，讀ㄨㄟˋ）**：不足「為」外人道也（向） |
| **乃** | 1. **連詞（於是、就）**：「乃」取一葫蘆置於地<br>2. **副詞（竟然、卻）**：「乃」不知有漢，無論魏晉<br>3. **繫詞（是）**：失敗「乃」成功之母 |
| **而** | 1. **順接（就、而且）**：學「而」時習之、舌一吐「而」二蟲盡為所吞<br>2. **轉折（卻、但是）**：出淤泥「而」不染、人不知「而」不慍 |
| **於** | 1. **在、從**：留蚊「於」素帳中<br>2. **比（表比較）**：苛政猛「於」虎<br>3. **被（表被動）**：勞力者治「於」人 |
| **然** | 1. **代詞（這樣）**：父利其「然」也、吳廣以為「然」（對、正確）<br>2. **連詞（然而、但是）**：「然」數十年來<br>3. **詞尾（……的樣子）**：欣「然」起行、怡「然」自得 |

### 2. 陌生文言文三步解題法
1. **抓人物與補主詞**：文言文極愛省略主詞！每遇到一個動詞，立刻在旁邊標註「誰做的？對誰做的？」（常考 A 對 B 說，下一句省略主詞其實已換成 B）。
2. **單音節詞換雙音節詞**：把古文單字造詞成現代雙字詞（例：「造」飲輒盡 ➔ 造訪；欣然「規」往 ➔ 規畫；請「循」其本 ➔ 依循）。
3. **看結尾議論句**：寓言或史傳類文言文，最後一句（「太史公曰」、「君子曰」或作者感嘆）往往直接點出全文主旨。

## 五、白話長文與圖表素養題解題法則

1. **「過度推論」與「無中生有」是最大陷阱**：
   - 選項若出現「**必定、絕對、所有、唯一、從此不再、最重要**」等極端詞，90% 是錯誤選項，務必回原文核對是否有如此絕對的因果關係。
2. **雙文本對讀題（甲文 vs. 乙文）**：
   - 先畫出小表格比較兩文的「**核心立場、論據、切入角度**」是「觀點相同但舉例不同」、「觀點互補」還是「觀點相反」。
3. **圖表題**：
   - 嚴格區分「百分比（%）」與「實際人數/總量」！佔比下降不代表實際數量下降（可能母體變大）。

## 六、寫作測驗衝六級分（四段式黃金架構）

會考作文多為「引導式命題」或「圖表資訊整合題」（不必抄題目提供的制式範例，要寫出**個人獨特經驗與深刻省思**）：

1. **第一段【破題與立意】（約 80～100 字）**：
   - 用「對比法」或「情境特寫法」開頭，避免「自古以來……」、「在日常生活中……」等老套開頭，直接點出題目核心概念。
2. **第二段【經驗鋪陳與轉折（起承）】（約 180～220 字）**：
   - 舉一個具體的自身經歷（小事大寫，加入五感描寫：視覺、聽覺、心理掙扎），描述起初的困境、誤解或迷惘。
3. **第三段【領悟與深化（轉）】（約 200～250 字，六級分關鍵！）**：
   - 寫出觸發改變的契機，並將「個人經驗」拉升到「人生哲理或社會觀察」的層次，展現思辨能力（例如：看到事情的一體兩面）。
4. **第四段【總結與首尾呼應（合）】（約 80～100 字）**：
   - 扣回第一段的意象，總結這份體悟對未來的影響，收尾乾淨俐落。
