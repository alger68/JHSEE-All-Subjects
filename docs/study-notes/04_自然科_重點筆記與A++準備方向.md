## 一、生物篇（國一上下）：恆定性、植物生理與遺傳

### 1. 細胞構造與物質進出
- **細胞胞器功能**：
  - **粒線體**：呼吸作用產生能量（ATP），稱為「細胞發電廠」（動植物皆有）。
  - **葉綠體**：行光合作用（注意：**植物表皮細胞無葉綠體**，但**保衛細胞有葉綠體**！）。
  - **液泡**：儲存水分、養分與廢物（成熟植物細胞有大型中央液泡）。
  - **細胞壁**：纖維素構成，維持形狀，**全透性**；**細胞膜**：磷脂＋蛋白質，具有**選擇性通透**。
- **小分子進出細胞膜**：
  - 直接擴散（過膜）：$\text{O}_2$、$\text{CO}_2$、水。
  - 特殊蛋白質通道（促進性擴散）：葡萄糖、胺基酸、礦物質離子、水（水可走兩條路！）。
- **滲透作用比較**：
  | 環境溶液 | 紅血球（動物細胞，無細胞壁） | 植物細胞（有細胞壁支撐） |
  | :--- | :--- | :--- |
  | **低張溶液（清水/純水）** | 吸水膨脹甚至**脹破** | 吸水膨脹，受細胞壁限制**不破裂**（氣孔打開） |
  | **高張溶液（濃食鹽水）** | 脫水**萎縮** | 細胞質脫水萎縮，發生**質離現象**（細胞膜與細胞壁分離） |

### 2. 植物構造、光合作用與運輸
- **光合作用兩階段（葉綠體內進行）**：
  - **光反應**：需要光、葉綠素；將水（$\text{H}_2\text{O}$）分解產生 **$\text{O}_2$（由氣孔釋出）** 並轉換能量。
  - **碳反應（暗反應）**：利用光反應的能量＋酵素，將 **$\text{CO}_2$（由氣孔進入）** 合成為 **葡萄糖** 與水。
- **維管束（木質部 vs. 韌皮部）與形成層**：
  - **方位口訣**：「**木內韌外，木上韌下**」（莖內側是木質部、外側是韌皮部；葉脈上方是木質部、下方是韌皮部）。
  - **木質部**：運輸**水分與礦物質**，方向**只能由下往上**（動力主要來自**蒸散作用**），老化的木質部形成木材（春材顏色淺細胞大、秋材顏色深細胞小，形成年輪）。
  - **韌皮部**：運輸**養分（蔗糖/有機物）**，方向**可上可下（雙向）**，樹皮包含韌皮部（環狀剝皮會導致根部缺乏養分死亡！）。

### 3. 人體消化、循環、呼吸、排泄與神經內分泌
- **消化酵素專一性與酸鹼環境**：
  - **唾液（澱粉酶）**：中性～微鹼性，澱粉 ➔ 麥芽糖。
  - **胃液（胃蛋白酶＋鹽酸）**：**強酸性**，蛋白質 ➔ 小分子肽類。
  - **膽汁（肝臟製造、膽囊儲存、注入小腸）**：**不含消化酵素**！僅以物理方式將脂質乳化成脂肪小球。
  - **胰液與腸液（注入小腸）**：**弱鹼性**，小腸是分解與吸收養分（絨毛）最主要的場所。
- **血液循環關鍵**：
  - **心臟四腔室**：「**左動右靜、上房下室**」（左心室、左心房充滿**充氧血**；右心室、右心房充滿**減氧血**）。
  - **微血管物質交換**（肺泡微血管與組織微血管均為擴散作用）：注意**肺動脈是減氧血，肺靜脈是充氧血**！
- **含氮廢物與排泄（氨 ➔ 尿素 ➔ 尿酸）**：
  - 人體蛋白質代謝產生劇毒的**氨** ➔ 由**肝臟**轉化為毒性較小的**尿素** ➔ 由**腎臟**過濾形成尿液排出。
- **神經系統與內分泌**：
  - **意識動作**（大腦參與：看到球揮棒） vs. **反射作用**（不經大腦：手遇燙縮回經**脊髓**；眨眼、打噴嚏、瞳孔縮放經**腦幹**）。
  - **血糖恆定**：飯後血糖高 ➔ **胰島素**（降血糖，促肝糖合成）；飢餓/運動 ➔ **升糖素**（升血糖，促肝糖分解）；緊急恐懼 ➔ **腎上腺素**（急升血糖、心跳加速）。

### 4. 細胞分裂、減數分裂與孟德爾遺傳
- **體細胞分裂 vs. 減數分裂**：
  - 體細胞分裂：複製 1 次、分裂 1 次 ➔ 產生 **2 個**子細胞，染色體數目 **不變（$2n$，成對）**。
  - 減數分裂（產生配子：精子/卵）：複製 1 次、分裂 **2 次**（第 1 次分裂時**同源染色體分離**，第 2 次複製染色分體分離） ➔ 產生 **4 個**子細胞，染色體數目 **減半（$n$，單套不成對）**。
- **ABO 血型與性聯遺傳**：
  - 血型基因型：A 型（$I^A I^A$ 或 $I^A i$）、B 型（$I^B I^B$ 或 $I^B i$）、AB 型（$I^A I^B$，等顯性）、O 型（$ii$）。
  - 人類性別決定在**父親的精子（$X$ 或 $Y$）**；紅綠色盲、血友病為 **$X$ 染色體隱性遺傳**（兒子的 $X$ 必來自母親！）。

## 二、理化篇（國二上下～國三上）：化學與物理核心

### 1. 化學核心：莫耳、酸鹼鹽、氧化還原與反應速率
- **莫耳計算公式**：
  $$\text{莫耳數 } (n) = \frac{\text{質量 } (m)}{\text{分子量 } (M)} = \frac{\text{粒子個數 } (N)}{6 \times 10^{23}}$$
  $$\text{體積莫耳濃度 } (M) = \frac{\text{溶質莫耳數 } (\text{mol})}{\text{溶液體積 } (\text{L})}$$
- **酸鹼指示劑變色口訣（酸性 ➔ 鹼性）**：
  - **石蕊**：紅 ➔ 藍
  - **酚酞**：無 ➔ 無（中性）➔ **紅**（鹼性）
  - **廣用指示劑**：紅橙黃（酸）➔ **綠（中性）** ➔ 藍靛紫（鹼）
- **pH 值與氫離子濃度**：
  - $[H^+] = 10^{-a}\text{ M} \implies \text{pH} = a$ ； 定溫 $25^\circ\text{C}$ 下，$[H^+] \times [OH^-] = 10^{-14}$。
  - **稀釋陷阱**：酸無論加水稀釋多少倍，pH 值只會**無限趨近於 7，絕不會超過 7 變鹼性**！
- **氧化還原與活性大小**：
  - **活性順序**：`鉀(K) > 鈉(Na) > 鈣(Ca) > 鎂(Mg) > 鋁(Al) > 碳(C) > 鋅(Zn) > 鐵(Fe) > 錫(Sn) > 鉛(Pb) > 氫(H) > 銅(Cu) > 汞(Hg) > 銀(Ag) > 鉑(Pt) > 金(Au)`
  - 活性大者：**易氧化（得氧／失電子）**，當**強還原劑**（在鋅銅電池中，活性大的**鋅片為負極（陽極）**，放出電子溶解變輕：$Zn \to Zn^{2+} + 2e^-$）。

### 2. 物理核心一：力學、壓力、浮力四大題型與功與能
- **浮力（阿基米德原理：$B = \text{排開液重} = V_{\text{液面下}} \times D_{\text{液}}$）四大秒殺法**：
  1. **浮體（$D_{\text{物}} < D_{\text{液}}$）**：**浮力 $B =$ 物重 $W$**（同一個物體浮在不同液體上，浮力永遠相等，都等於物重！液體密度越大，沒入體積越小）。
  2. **沉體（$D_{\text{物}} > D_{\text{液}}$）**：**浮力 $B = V_{\text{物體全部}} \times D_{\text{液}} < W$**（同體積的鐵球與鋁球全沉入水中，排開水體積相同，故**浮力相等**！）。
  3. **彈簧秤在水中的讀數**：$\text{浮力 } B = W_{\text{空氣中重}} - W_{\text{液體中讀數}}$。
  4. **冰塊熔化液面變化**：冰浮於純水（$D=1$）熔化後液面**不變**；冰浮於食鹽水（$D>1$）熔化後液面**上升**。
- **牛頓三大運動定律與 $v-t$ 圖**：
  - **$v-t$ 圖斜率 ＝ 加速度 $a$** ； **$v-t$ 圖與時間軸圍成的面積 ＝ 位移 $\Delta x$**。
  - **合力 $F = m \times a$**：當等速運動（或靜止）時，加速度 $a = 0 \implies$ **所受合力必為 $0$**（動摩擦力大小等於水平推力！）。
  - **作用力與反作用力** vs. **平衡力**：
    - 作用力與反作用力：作用在**不同物體**上，不可抵消。
    - 平衡力：作用在**同一物體**上，可互相抵消。
- **功與力學能守恆**：
  - $\text{功 } W = F \times S$（力與位移同向做正功、反向做負功、**垂直時不做功 $W=0$**，如手提重物水平行走、向心力）。
  - $\text{動能 } E_k = \frac{1}{2}mv^2$ ； $\text{重力位能 } U = mgh$。

### 3. 物理核心二：波動、光學、電學與磁學
- **波速 $v = f \times \lambda = \frac{\lambda}{T}$**：**波速只取決於「介質種類與狀態（如溫度、繩張力）」**，甩動快慢只改變頻率 $f$ 與波長 $\lambda$，不改變波速！
- **光的折射口訣**：「**快大慢小**」（光速在空氣 $>$ 水 $>$ 玻璃；光速越快，與法線夾角越大）。
- **電學串並聯與電功率（國三上大魔王）**：
  - 歐姆定律：$V = I \times R$ ； 電功率：$P = \frac{E}{t} = I \times V = I^2 R = \frac{V^2}{R}$。
  - **燈泡亮度看「實際消耗電功率 $P$」**：
    - **串聯電路（電流 $I$ 相同）**：用 **$P = I^2 R$** ➔ 電阻 $R$ 越大越亮！
    - **並聯電路（電壓 $V$ 相同）**：用 **$P = \frac{V^2}{R}$** ➔ 電阻 $R$ 越小越亮！
- **電流磁效應（安培右手定則） vs. 載流導線受力（右手開掌定則） vs. 電磁感應（冷次定律）**：
  | 現象 | 能量轉換 | 核心原理與定則 | 應用實例 |
  | :--- | :--- | :--- | :--- |
  | **電流磁效應** | 電能 ➔ 磁能 | 有電流就有磁場（**安培右手定則**） | 電磁鐵、電鈴 |
  | **電流在磁場受力** | 電能 ➔ 力學能 | 通電導線在外磁場中受力（**右手開掌定則**：拇指電流、四指磁場、掌心受力） | **電動機（馬達）**、安培計 |
  | **電磁感應** | 力學能 ➔ 電能 | **磁場發生變化**才產生感應電流（**冷次定律**：反抗磁場變化） | **發電機**、變壓器（僅限交流電） |

## 三、地球科學篇（國三上）：地質、大氣與天文

### 1. 板塊構造與台灣地質
| 邊界類型 | 應力性質 | 代表地形與地質構造 |
| :--- | :--- | :--- |
| **張裂性板塊邊界** | 拉張力（**正斷層**：上盤下滑） | **中洋脊**（玄武岩，新海洋地殼誕生處）、東非大裂谷 |
| **聚合性板塊邊界** | 擠壓力（**逆斷層**：上盤上移、褶皺） | **海溝**（老海洋地殼隱沒消亡處）、火山島弧、褶皺山脈（喜馬拉雅、**台灣島**） |
| **錯動性板塊邊界** | 剪力（平移斷層） | 轉形斷層 |

- **台灣板塊交界**：位於**歐亞板塊（西側）**與**菲律賓海板塊（東側）**聚合處，交界帶為**花東縱谷**。
  - 北台灣：**菲律賓海板塊向北隱沒**到歐亞板塊下（形成琉球海溝、大屯火山群、龜山島，震源由南向北變深）。
  - 南台灣：**歐亞板塊向東隱沒**到菲律賓海板塊下（形成馬尼拉海溝、綠島、蘭嶼）。
- **地震規模 vs. 地震強度（震度）**：
  - **地震規模（芮氏規模，有小數點）**：代表地震釋放的**總能量**，一次地震全世界測得只有**一個**數值。
  - **震度（0～7 級整數）**：代表某地**搖晃與破壞程度**，隨距離震央遠近、地質鬆軟而不同。

### 2. 天氣系統與台灣四季氣象
- **北半球高低氣壓口訣（右手定則）**：
  - **低氣壓（氣旋）**：大拇指朝**上（中心上升氣流 ➔ 降溫凝結成雲致雨，陰雨天）**，四指**逆時針向內旋入**。
  - **高氣壓（反氣旋）**：大拇指朝**下（中心下沉氣流 ➔ 增溫水氣蒸發，晴朗天）**，四指**順時針向外旋出**。
- **鋒面比較**：
  - **冷鋒**（藍三角）：冷空氣推暖空氣，鋒後降雨、雨區窄、歷時短、強度大（陣雨）、過境後氣溫驟降。
  - **暖鋒**（紅半圓）：暖空氣爬升冷空氣上，鋒前降雨、雨區廣、綿綿細雨、過境後氣溫回升。
  - **滯留鋒**（紅藍相間）：5～6 月冷暖氣團勢力相當，形成台灣**梅雨**。

### 3. 天文：四季太陽軌跡、月相與潮汐（A++ 決勝區）
- **台灣（嘉南北回歸線 $23.5^\circ\text{N}$ 以北，如台北 $25^\circ\text{N}$）四季太陽視運動軌跡**：
  - **春分 (3/21) & 秋分 (9/23)**：**正東升、正西落**，晝夜等長（各 12 小時）。
  - **夏至 (6/22)**：太陽直射北回歸線（$23.5^\circ\text{N}$），**東偏北升、西偏北落**，晝最長夜最短；正午太陽在嘉南頭頂正上方（仰角 $90^\circ$），在台北則略偏**南方**天空（正午日影朝**正北**！）。
  - **冬至 (12/22)**：太陽直射南回歸線（$23.5^\circ\text{S}$），**東偏南升、西偏南落**，晝最短夜最長；正午太陽仰角最小，正午日影最長（朝正北）。
- **月相、日月食與潮汐關係表**：
  | 農曆日期 | 月相名稱 | 日、地、月位置 | 出沒時間（口訣） | 天文現象與潮汐 |
  | :--- | :--- | :--- | :--- | :--- |
  | **初一** | **新月（朔）** | 日—**月**—地（一直線） | 同升同落（06:00升、12:00中天、18:00落），整夜不可見 | 可能發生**日食**；**大潮**（潮差最大） |
  | **初七、初八** | **上弦月**（西半亮） | 日地月夾角 $90^\circ$ | 12:00升、**18:00中天**、24:00落（上半夜可見於西方） | **小潮**（潮差最小） |
  | **十五、十六** | **滿月（望）** | 日—地—**月**（一直線） | 此升彼落（18:00東升、**24:00中天**、06:00西落），整夜可見 | 可能發生**月食**；**大潮**（潮差最大） |
  | **廿二、廿三** | **下弦月**（東半亮） | 日地月夾角 $90^\circ$ | 24:00升、**06:00中天**、12:00落（下半夜可見於東方） | **小潮**（潮差最小） |

  - **潮汐時間推算**：每天有 2 次滿潮、2 次乾潮；**每一次滿潮到下一次乾潮間隔約 6 小時 12.5 分鐘**；**隔天滿潮時間會比前一天延後約 50 分鐘**（因為月球公轉）。
