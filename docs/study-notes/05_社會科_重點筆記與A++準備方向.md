## 一、地理篇：地圖判讀、全球氣候與區域特色

### 1. 經緯度、時區與等高線地形圖（必考基本功）
- **經線 vs. 緯線**：
  - **經線（南北向，指示東西位置）**：決定**時區**。全球 $360^\circ$ 分 24 時區，**每差 $15^\circ$ 相差 1 小時，「東加西減」**（台灣採 $120^\circ\text{E}$ 中原標準時間 $\text{UTC}+8$；英國倫敦本初經線 $0^\circ$）。
  - **緯線（東西向，指示南北位置）**：決定**氣候帶**（低緯熱帶 $0^\circ\text{～}23.5^\circ$、中緯溫帶 $23.5^\circ\text{～}66.5^\circ$、高緯寒帶 $66.5^\circ\text{～}90^\circ$）。
- **比例尺大小比較**：
  - 分母越小 ➔ 比例尺越**大** ➔ 涵蓋實際範圍越**小**、內容越**詳細**（如：校園平面圖 $\frac{1}{1000} >$ 世界地圖 $\frac{1}{100000000}$）。
  - 注意：**面積縮放是比例尺的「平方倍」**！
- **等高線判讀口訣**：「**V 字尖端指向高處（上游）＝ 河谷（集水線，可發育河流）**」；「**V 字尖端指向低處 ＝ 山脊（分水嶺）**」；等高線越密集代表坡度越**陡**。

### 2. 全球氣候類型判讀終極口訣：「以溫定帶，以水定型」
看到「氣候圖（氣溫折線＋雨量柱狀圖）」，按以下三步驟秒殺：

1. **先看最高溫在幾月（判別南北半球）**：
   - **6～8 月最高溫** ➔ **北半球**（氣溫曲線向上凸 $\cap$）
   - **12～2 月最高溫** ➔ **南半球**（氣溫曲線向下凹 $\cup$）
2. **再看最冷月均溫（以溫定帶）**：
   - 最冷月 $> 18^\circ\text{C}$ ➔ **熱帶氣候**
   - 最冷月 $0^\circ\text{C} \sim 18^\circ\text{C}$ ➔ **溫帶（副熱帶）氣候**
   - 最冷月 $< 0^\circ\text{C}$ ➔ **溫帶大陸性 / 季風（寒溫帶）氣候**
3. **最後看雨量季節分布（以水定型）**：
   | 氣候類型 | 氣溫與雨量特徵 | 分布地區與代表農業/景觀 |
   | :--- | :--- | :--- |
   | **熱帶雨林** | 全年高溫多雨（午後對流雨），年溫差極小 | 赤道南北 $10^\circ$（亞馬遜、剛果、印尼）；熱帶栽培業、游耕 |
   | **熱帶莽原** | 夏雨冬乾（ITCZ 與副熱帶高壓交替），乾溼季分明 | 雨林兩側（非洲疏林草原、巴西高原）；大型野生動物遷徙 |
   | **熱帶季風** | 夏雨冬乾，但**雨季雨量極端集中且總量極大** | 南亞（印度）、東南亞（中南半島）、台灣南部；稻作農業 |
   | **熱帶沙漠** | 全年少雨（$<250\text{mm}$），日夜溫差極大 | 南北回歸線附近（副熱帶高壓籠罩：撒哈拉、阿拉伯、澳洲中部） |
   | **溫帶地中海型** | **夏乾冬雨**（唯一溫帶冬雨型！夏受副高、冬受西風） | 緯度 $30^\circ\text{～}40^\circ$ 大陸**西岸**（環地中海、加州、智利中部、南非開普敦、澳洲西南）；耐旱作物（橄欖、葡萄、柑橘） |
   | **溫帶海洋性** | **全年有雨**，冬暖夏涼（年溫差小，受**西風＋暖流**影響） | 緯度 $40^\circ\text{～}60^\circ$ 大陸**西岸**（西歐、西北歐、紐西蘭）；酪農業 |
   | **夏雨型暖溫帶 / 溫帶季風** | 夏雨冬乾（受季風影響），季風區年溫差較同緯度大 | 大陸**東岸**（中國華北/華中、日本、韓半島、美國東南部） |
   | **溫帶大陸性** | 夏雨為主，年雨量少，**年溫差極大**（冬嚴寒 $<0^\circ\text{C}$） | 中高緯大陸內部（東歐、俄羅斯、北美中部大平原）；商品化穀物（春麥/冬麥） |

### 3. 台灣自然與人文地理重點
- **五大地形**：山地、丘陵、台地（林口、桃園、大肚、八卦）、盆地（台北、台中、埔里）、平原（嘉南平原最大、屏東平原、宜蘭蘭陽平原）。
- **四大海岸**：北部（**岬灣海岸**，東北季風＋差異侵蝕）、西部（**沙岸/洲潟海岸**，平坦多潟湖沙洲，養殖漁業與鹽田）、南部（**珊瑚礁海岸**，恆春半島）、東部（**斷層海岸**，陡峭緊鄰太平洋）。
- **水資源與河川**：台灣河川**坡陡流急（荒溪型河川）**，西南部冬季枯水期明顯，故**中南部水庫數量遠多於北部**（曾文水庫容量最大）。

### 2. 中國史與世界史高頻考點
- **中國歷代選官制度演變**（必考！）：
  `西周「封建世襲」 ➔ 漢代「察舉制度」（孝廉，看品德但易被世族把持） ➔ 魏晉南北朝「九品官人法」（上品無寒門，下品無世族，造成世族政治） ➔ 隋唐至清末「科舉制度」（分科考試，促進社會階層流動，宋代更加嚴密糊名謄錄） ➔ 1905 清末廢除科舉`
- **中國近現代重要轉折**：
  - **鴉片戰爭 (1840)**：割香港島、五口通商、領事裁判權、片面最惠國待遇、協定關稅。
  - **自強運動 (1860s-1895)**：「師夷長技以制夷」，只學**器物（船堅砲利）**，甲午戰爭失敗宣告破產。
  - **戊戌變法 (1898) & 立憲運動**：改革**制度（君主立憲）**。
  - **新文化運動 (1915起) & 五四運動 (1919)**：改造**思想文化**（德先生 Democracy 與賽先生 Science、白話文運動）。
- **世界史核心脈絡**：
  - **古希臘（雅典民主 vs. 斯巴達軍國） ➔ 亞歷山大「希臘化文化」（歐亞非融合） ➔ 羅馬（共和 ➔ 帝國，《十二表法》、基督教興起）**。
  - **歐洲近代四部曲**：
    1. **文藝復興 (14-16世紀)**：義大利起源，**人文主義**（以人為本，擺脫神權束縛）。
    2. **宗教改革 (16世紀)**：馬丁路德《九十五條論綱》（因信稱義）、喀爾文、英國國教派。
    3. **科學革命 (16-17世紀)**：哥白尼、伽利略、牛頓，重視實驗與歸納演繹。
    4. **啟蒙運動 (18世紀)**：理性主義，洛克（天賦人權）、孟德斯鳩（三權分立）、盧梭（主權在民、社會契約），直接影響**美國獨立與法國大革命**！

### 3. 經濟學核心：機會成本、供需法則與匯率（必考計算與推論）
- **機會成本**：選擇某方案時，在**被放棄的選項中「價值最高」的那一個**（加上實際支出的外顯成本）。
- **比較利益法則（國際貿易與專業分工）**：
  - 誰生產某產品的「**機會成本較低**」，誰就擁有該產品的「比較利益」，應專業生產並出口該產品！（就算甲國兩樣產品產量都贏乙國〔絕對利益〕，只要機會成本不同，分工貿易雙方皆能獲利）。
- **需求法則（消費者） vs. 供給法則（生產者）**：
  - **「價格（P）」本身改變** ➔ 在同一條供需曲線上做「**點移動**」（例：雞排漲價，消費者的**需求量減少**，生產者的**供給量增加**）。
  - **「價格以外因素」改變**（如所得、偏好、天氣、生產成本、預期心理）➔ 整條曲線「**線移動**」（稱為**需求／供給變動**）。
- **匯率升貶值對進出口與旅遊的影響（A++ 必背表格）**：
  - 例：原本 $1\text{ 美元} = 30\text{ 台幣}$ ➔ 變成 **$1\text{ 美元} = 32\text{ 台幣}$**：
    - 代表 1 美元可以換更多台幣 ➔ **美元升值、台幣貶值**！
  | 台幣變化 | 對「進口商 / 出國旅遊 / 留學生」 | 對「出口商（台商外銷） / 外國人來台觀光」 |
  | :--- | :--- | :--- |
  | **台幣升值**（例：$32 \to 28$） | **有利！**（買外國貨變便宜、出國玩更划算） | **不利！**（台灣商品在國外變貴，或換回台幣變少） |
  | **台幣貶值**（例：$30 \to 32$） | **不利！**（買進口貨變貴、出國成本增加） | **有利！**（台灣商品在國外變便宜，更具價格競爭力） |
