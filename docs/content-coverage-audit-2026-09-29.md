# All Subjects 題庫覆蓋盤點與擴充紀錄

日期：2026-09-29  
範圍：JHSEE All Subjects 原創題庫（不含官方歷屆卷）  
依據：116 年國中教育會考官方資訊與十二年國教第四學習階段課綱。

> 本文件的「目標題數」是本專案為了避免重複題、支援錯題變形複習而設定的內部題庫深度目標，不是官方規定的題數。

## 1. 三年考點藍圖

建立 `data/curriculum-blueprint.json`：

- 五科：國文、英文、數學、自然、社會
- 每科 12 個核心能力
- 每科國一、國二、國三各 4 個能力節點
- 合計 60 個能力節點
- 每能力長期目標 8～12 題
- 每個能力包含 domain、grade、priority、aliases 與 targetQuestions

藍圖主要用途不是標示課本章名，而是讓系統知道：

`科目 → 年級 → 領域 → 核心能力 → 題庫深度`

## 5. Pack 架構

正式網站保留原本 205 題核心題庫；Supplemental Pack 使用：

`public/question-packs/manifest.json`

新增下一批題庫時只需要：

1. 新增一個 JSON 題庫 Pack。
2. 在 manifest 新增一筆。
3. 執行 `npm run audit:content`。
4. 執行 `npm test` 與 `npm run build`。

不需要再修改 `app.js` 的題庫檔名清單。

Pack 載入失敗採 fail-soft：

- 核心 205 題仍可正常使用。
- 單一 Supplemental Pack 失敗只記 warning。
- 不會因新增題包失敗讓整個網站無法開啟。

## 6. 下一批優先順序

Pack 002 優先增加目前題數仍偏薄的能力：

1. 英文國三：跨段整合、圖表證據、長篇推論。
2. 數學國三：相似形、圓、二次方程式、統計機率。
3. 自然：國一探究設計、國三跨科證據推論。
4. 社會：公共議題、跨資料整合、國一基礎史地公民。
5. 國文：資料閱讀、作者意圖、跨文本論證。

長期目標不是「剛好 1,000 題」，而是讓 60 個能力節點大多具有 **8～12 題以上、不同情境與不同表現形式**，才能真正降低重複與背答案問題。


## 7. Pack 002：再新增 75 題

第二批仍採五科各 15 題，但不再平均補題，而是優先補最薄的高價值能力：

- 社會：全球化、公共議題、法律原則、跨史料／地圖／統計。

## 8. 下一階段

Pack 003 不需要再追「能力是否有題」，而要開始看：

1. 同一能力是否至少有 4～6 種不同情境／stimulus form。
2. 同一能力是否同時有基礎確認、標準題、近遷移與資料整合題。
3. 國一、國二仍偏薄的科目要回補，避免題庫過度集中國三。
4. 配合 Question Provider V2 的 fingerprint / variation form，確保錯題複習真正能抽到不同題。


## 9. Pack 003：再新增 75 題＋題型形式多樣化

Pack 003 的目標從「補能力深度」再往前一步，開始要求 Provider 能辨識題目的表現形式。

新增 variation form 自動分類：

- table
- dialogue
- notice
- email
- chart
- experiment
- passage
- standalone

如果題目沒有手動填 variationForm，Registry 會依材料與題型自動推定，供 Question Provider 避免同一能力連續出現相同形式。
