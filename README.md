# JHSEE Adventure｜116 會考大冒險

手機優先的全科 RPG 會考學習平台，整合五科關卡、戰鬥答題、Boss、EXP、Combo、每日任務、錯題復仇、能力分析與快速模考。

## V1 功能

- 國文、英文、數學、自然、社會五個世界
- 5 題普通關卡與 10 題 Boss 挑戰
- HP、Combo、EXP、等級、金幣與星級
- 每日任務、10 題 Streak 門檻及每日寶箱
- 錯題熟練度與間隔複習日期
- 自適應學習引擎：每次作答更新 0–100 核心能力熟練度、Priority、連錯狀態與 1/3/7/14/30 天複習排程
- 動態科目權重：以第一次模考為底盤，依實際作答弱點平滑修訂，並設科目上下限防止偏科
- 短練習自動混合 45% 弱點修復、25% 到期複習、20% 會考混合、10% 強項維持／挑戰；題量不足時自動補滿且不重複
- 連錯 1/2/3/4+ 次依序切換確認、近遷移、補救、診斷模式；分析頁顯示動態比例與最高優先核心能力
- 跨科快速模考；交卷前不顯示答案
- LocalStorage 自動存檔，無須登入

## 官方會考與補強中心

入口：`#/exam-center`。

- 115 年官方國文、英文閱讀、英聽、數學、社會、自然站內原題與計時答案卡，共 235 題選擇題；英聽為三選一。
- 寫作 50 分鐘草稿、數學 2 題非選筆記及官方評分樣卷入口。這些項目不自動評分。
- 作答與開始時間保存在目前瀏覽器，重新整理可續答；離開頁面也持續計時。交卷後才呈現核對答案。
- 頂端及末題都有交卷按鈕；倒數只更新時間文字，不再每秒重繪整頁或捲回頂端。
- 點「交卷」先進入站內檢查頁：顯示未答與不確定題號，可直接返回補答，再按「確認交卷」。此流程不使用瀏覽器原生確認視窗；檢查期間仍會計時與到時交卷。
- 205 題原創練習，其中 150 題為已核對的會考導向閱讀、情境應用、資料分析與推論題，含領域、題型、能力與本站核對依據。
- 原創短練習可依科目、年級範圍與題型篩選；保留首次／重做與提示使用紀錄。
- 原創短練習預設使用 150 題已核對的會考導向題；可另選 55 題基礎補強或全部 205 題。篩選時立即顯示符合題數，沒有符合題目時提示調整條件。
- 錯題、猜對及使用提示的題目納入複習；可自行記錄錯因。同一天反覆答對不重複增加熟練度，再答錯仍會降低熟練度。

官方題目可切換「逐題作答」與「整份題本」，原文章與圖表留在本站，並支援放大閱讀；原 PDF 下載是額外選項。英聽可在站內播放官方完整音檔。切換模式、選答案與換題會保留倒數和作答；播放器獨立存在，不會因換題重建。本站沒有官方授權合作或正式等級換算。原創會考導向標記是本站分類與核對，不等同官方命題或審定；另外 55 題基礎題沒有自動加上會考導向標記。來源與查核範圍見 [官方來源紀錄](docs/official-sources.md)。

最近 10 份完整報告（含非選／寫作草稿）可在會考中心重新開啟，重要草稿請自行另存。

學習資料只保存在這台裝置的瀏覽器，沒有帳號或跨裝置同步。數學非選與寫作須自行對照官方樣卷。

## AI 弱點變形題（Vercel）

Adaptive Engine 已可選配 Vercel Functions 後端產生針對性變形題。瀏覽器不持有 OpenAI API Key；只送出科目、核心能力、熟練度、Priority、訓練模式，以及一題既有題作為「不可複製」的能力參考。

- 僅在已有核心能力資料且 Priority >= 50 時嘗試 AI 生成。
- Priority 50–69 產生 2 題、70+ 產生 3 題、診斷模式產生 4 題。
- 後端每次最多接受 5 題，並限制輸出 token；預設使用 `gpt-5.6-luna`。
- 使用 Responses API Structured Outputs（JSON Schema）固定題目格式，再做第二層本地 QA：科目、領域、核心能力、難度、四選一、唯一 ID、不可原題複製等。
- 第一次生成未通過 QA 時自動重試一次；仍失敗則回傳錯誤。
- 前端 API 失敗、超時或未設定時，直接使用原有 Adaptive 題庫，不阻斷學習。
- AI 題庫池最近保留 200 題在 LocalStorage；短練習優先避開最近做過的題，並把已核對格式的 AI 題納入後續題庫池。錯誤選項的 errorTags 會寫入錯因紀錄。

Vercel 環境變數請依 `.env.example` 設定：

- `OPENAI_API_KEY`：必要，僅放 Vercel。
- `AI_QUESTION_MODEL`：預設 `gpt-5.6-luna`。
- `AI_ALLOWED_ORIGINS`：允許呼叫 API 的前端來源，預設 `https://alger68.github.io`。
- `AI_MAX_OUTPUT_TOKENS`：每次生成的輸出上限，預設 2400。
- `AI_RATE_LIMIT_PER_MINUTE`：單一 Function instance 每個 client 每分鐘最多生成請求數，預設 6；正式公開服務另建議在 Vercel Firewall 對 `/api/generate-question` 設 IP rate limit。

部署後，Vercel 網站本身會自動使用同網域的 `/api/generate-question`。若仍以 GitHub Pages 為主要入口，請把 Vercel 專案根網址填入 `js/config/ai-service.js` 的 `deployedService`，GitHub Pages 就會跨網域呼叫 Vercel API。
